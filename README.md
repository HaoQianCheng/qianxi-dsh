# 富江DSH完美破甲

富江破甲是用于 DSH 的本地插件，内置提示词规则，支持 Windows 一键安装、自动准备缺失运行环境和一键卸载。插件加载后，在对话输入框上方显示「富江破甲已激活」。

当前版本：0.4.3。

## 安装使用

1. 安装并启动过一次 DSH，生成本地配置目录。
2. 下载发布页的 ZIP 安装包，完整解压。
3. 完全退出 DSH，双击「点我一键注入.bat」。
4. 按提示选择需要使用的 DSH 配置，等待安装完成。缺少 Node.js、npm 或 pnpm 时会自动下载准备，首次安装需要联网。
5. 重新启动 DSH，确认对话框上方显示「富江破甲已激活」。
6. 在聊天中输入激活词「富江」。

## 卸载

完全退出 DSH，双击解压目录中的「点我一键卸载.bat」，选择此前安装的配置。完成后重新启动 DSH。

## 常见问题

- 找不到配置：先安装并启动一次 DSH。
- 下载失败：检查网络是否能访问 Node.js 官方网站及 npm 软件包源。
- 找不到脚本：保留完整解压目录，不要只复制单个 BAT 文件。
- 安装或卸载后显示没有变化：完全退出并重新启动 DSH，确认操作的是当前使用的配置。
